# Hermes Agent Hands-on Training
**Web Dashboard Development, Agent Capabilities & Freelance Launch**
*By School Of Freelancing*

---

## 📌 Overview

A 6-day intensive Training covering end-to-end Hermes Agent dashboard development, secure deployment, advanced agent capabilities, and a complete freelancing launch workflow — from job search to first withdrawal. No video tutorials only Instructor-Led Hands-on Training

| | |
|---|---|
| **Total Duration** | 30 Hours · 6 Working Days  |
| **Schedule** | 5 Sessions/Week · 5 Hours/Session |
| **Format** | Instructor-Led Training + Hands-On Training |
| **Level** | Beginner to Job-Ready |
| **Freelance marketplace** | Upwork & Freelancer
| **Prerequisite** | Linux server, domain, Cloud AI API, Telegram Bot & Linux terminal familiarity |

---

## 🎯 Learning Outcomes

By the end of this Training, students will be able to:
- Build and deploy a Hermes Agent web dashboard
- Secure remote access using Tailscale
- Connect Hermes Agent to Telegram and an AI model provider
- Teach the agent reusable skills to automate repeat tasks
- Configure Tools, Skills, Memory, Context Files, MCP, Cron, Delegation, Code Execution, Browser, Hooks, Batch Processing, and Provider Routing
- Client acquisition service development as a freelancer using Upwork, Freelancer.com and service 5 service videos publish at YouTube
- Land clients via direct outreach and global marketplaces
- Search, apply, and win freelance jobs
- Deliver work, collect feedback, and withdraw earnings
- Guaranteed Income Based On Two Conditions:
Attend all training regularly and don't leave training due to personal issue or any technical glitches and need to purchase the necessary bids/connects on the freelance marketplace to apply jobs

## 🗂️ Day-by-Day Outline

### Day 1 — Dashboard Foundations
**Duration:** 5 Hours
- Hermes Agent architecture overview
- Environment setup & dependencies
- Building the web dashboard (UI, monitoring panels, agent controls)
- Hands-on lab: deploy a working local dashboard

### Day 2 — Secure Connectivity & AI Integration
**Duration:** 5 Hours
- Securing the dashboard & agent access with **Tailscale**
- Connecting Hermes Agent to **Telegram** (bot setup, API/webhooks)
- Integrating an **AI model provider** (API keys, configuration)
- Hands-on lab: agent responds live via Telegram

### Day 3 — Core Agent Capabilities I
**Duration:** 5 Hours
- **Tools** — connecting built-in and custom tools
- **Skills** — teaching reusable skills to automate repeat tasks
- **Memory** — persistent memory configuration
- **Context Files** — feeding structured context to the agent
- Hands-on lab: build one custom automated skill

### Day 4 — Core Agent Capabilities II
**Duration:** 5 Hours
- **MCP** (Model Context Protocol) integration
- **Cron** — scheduled/recurring tasks
- **Delegation** — assigning sub-tasks to other agents
- **Code Execution** — running code within agent workflows
- **Browser** — web browsing/automation actions
- **Hooks** — event-triggered automation
- **Batch Processing** — handling multiple tasks at once
- **Provider Routing** — switching/routing between AI providers
- Hands-on lab: chain 3+ capabilities into one automated workflow

### Day 5 — Freelance Service Setup
**Duration:** 5 Hours
- Setting up **Upwork** and **Freelancer.com** profiles
- Building your service offer (portfolio, pricing, gig descriptions)
- Searching for relevant jobs & writing winning proposals
- Hands-on lab: apply to 3 live job postings

### Day 6 — Client Delivery & Earnings
**Duration:** 5 Hours
- Delivering finished work professionally
- Handling client revisions & communication
- Collecting feedback and managing reviews/reputation
- Withdrawing earnings (payment methods, fees, timelines)
- Wrap-up: building a repeatable freelance workflow
